This is the github repo for paper: **Defending Against Deepfake Speech Attacks via Feature Dropout and Dropin Regularization in Large Audio Language Models**

The paper link: https://www.frontiersin.org/journals/artificial-intelligence/articles/10.3389/

We use the SALMOON backbone, so please refer to their github for more details on how to set up environment.

The data are in the folder and related run, train python file are given.
